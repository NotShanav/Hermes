Hermes v1.3.0 (desktop app 1.3.0 on Hermes core beta-0.1), 2026-11-09
Contains: Hermes core + desktop app (app/) + CI workflow + repo README.
Compiled by the author on GitHub Actions: NOT YET for this version (v1.2.1 compiled and ran; the changes below are new and untested).

New in v1.3.0
- Tray menu modernised (crates/hermes-tray). Recording logic is untouched.
  * Status header with a coloured dot (same artwork as the tray icon: red recording, grey paused, ring locked/asleep,
    amber warning). Clicking it opens the status dialog. Summary line underneath.
  * Grouped: "Pause for..." submenu (15 minutes, 1 hour) and a "Settings" submenu (start with Windows, start recording when
    Hermes starts, on-screen dot, edit exclusions). Top level is down to nine entries.
  * Plain wording: "Pause recording" / "Resume recording", "Open Hermes".
  * Follows the Windows light/dark app theme (uxtheme ordinals 135/136; falls back to the light menu if unavailable).
  * Per-monitor DPI awareness: the tray icon, the menu and the recording dot are drawn at the real display resolution
    instead of being stretched (the old look was blurry on scaled displays). The recording dot scales with the display.
  * Friendlier start-up notification text.
- Repo README and the versioned-package workflow are now part of the project (previously separate files).

Not changed (Windows owns them): the "Show hidden icons" flyout and the look of the notification balloon.

Since v1.2.1: tray changes above only. App UI unchanged.
Earlier features still present: Modern/Fluidity interface styles, liquid-glass UI, zoomable ribbon and lanes,
USB-removal auto-lock, hidden clean-slate reset, author tag NotShanav.
